# Librairie de directions artistiques

**30 mood boards prêts à coller, pour lancer un design de site sans repartir de zéro.**

Un fichier HTML autonome. On l'ouvre dans un navigateur, on parcourt des aperçus de site rendus en direct dans leur propre style, on en retient une à trois, et on récupère un brief structuré à coller dans Claude Design.

---

## Pourquoi

Décrire une direction artistique à l'oral, c'est lent et imprécis. « Quelque chose de propre mais avec du caractère » ne produit rien de mémorable. Cette librairie remplace la description approximative par un brief complet : lignée de références, hex exacts, couple typographique, règles de composition — et surtout la liste des interdits, qui est souvent ce qui empêche un design de retomber dans le générique.

## Démarrage

```
Ouvrir librairie-moodboard.html dans un navigateur.
```

Aucune installation, aucune dépendance à part les Google Fonts (des polices de repli prennent le relais hors ligne).

## Les trois gestes

| | |
|---|---|
| **01 · Parcourir** | Filtrer par tag, chercher un mot (« grille », « néon », « papier »), ou cliquer **Au hasard** pour sortir de ses réflexes. |
| **02 · Composer** | Ajouter une à trois directions au brief. Activer les réglages transverses : grain, mouvement, densité, format. |
| **03 · Générer** | Renseigner le sujet et le format, copier le brief, coller dans Claude Design. |

## Anatomie d'une fiche

Chaque direction ouvre un panneau qui contient :

- **Aperçu vivant** — une mini-page rendue dans le style lui-même. On juge à l'œil, pas en lisant une liste de codes hexadécimaux.
- **Lignée** — d'où vient ce langage visuel : écoles, affichistes, objets, époques.
- **Palette** — six rôles (fond, surface, texte, secondaire, accent, accent 2). Un clic sur une pastille copie son hex.
- **Typographie** — un couple titre / texte, avec un spécimen réel.
- **Mise en page** — les règles de composition propres à la direction.
- **À éviter** — les gestes qui la trahissent. La section la plus utile du lot.
- **Se marie bien avec** — deux directions compatibles, cliquables.

## Réglages transverses

Huit axes indépendants du style, cochables au moment de générer le brief. Ils règlent le tempo, pas le langage.

| Réglage | Effet sur le brief |
|---|---|
| Grain & matière | Texture discrète sur toute la page, sans gêner la lecture. |
| Mouvement au scroll | Une seule séquence de révélation, pas d'effets dispersés. |
| Zéro animation | Page immobile, tout se joue dans la composition. |
| Photo en héros | Image plein cadre, texte posé dessus. |
| Type en héros | Héros purement typographique, aucune image. |
| Dense | Beaucoup d'information par écran, hiérarchie fine. |
| Très aéré | Une idée par écran, marges généreuses. |
| Mobile d'abord | Composition à 390 px, puis élargissement. |

`Dense` et `Très aéré` s'annulent, comme `Mouvement au scroll` et `Zéro animation`. Choisir un camp.

## Mélanger deux ou trois directions

Un mélange à parts égales donne de la bouillie. Le brief impose donc une hiérarchie explicite :

1. **La première direction porte la structure** — grille, rythme, mise en page.
2. **La deuxième porte la couleur et l'énergie** — palette, température, densité.
3. **La troisième n'est qu'une touche** — un seul détail signature, pas davantage.

En cas de règles contradictoires, la première l'emporte. C'est écrit noir sur blanc dans le brief généré.

## Exemple de sortie

```
Conçois une page web avec la direction artistique suivante.

Sujet : portfolio d'un atelier de céramique
Format : une seule page, 4 sections

DIRECTION : Calme japonais × Risographie

— 1. Calme japonais
Le vide comme matériau, un seul geste coloré.
Références : direction artistique de Kenya Hara pour Muji, …
Palette : fond #F7F5F0, surface #EBE7DF, texte #33312D, …
Typographie : titres en Work Sans 300, texte courant en Work Sans 300.
Mise en page : marges immenses, un seul élément par écran, …
À éviter : accents vifs, gras lourds, densité, …

— 2. Risographie
…

Fusion : prends la structure, la grille et le rythme de « Calme japonais »
comme base. Emprunte la palette et l'énergie de « Risographie ».
En cas de conflit entre deux règles, la première direction l'emporte.

Réglages :
- Ajoute une texture de grain discrète sur toute la page…
- Très aéré : une seule idée par écran…

Exigences : responsive jusqu'au mobile, focus clavier visible, mouvement
réduit respecté. Écris le contenu réel plutôt que du faux texte.
```

## Ajouter une direction

Tout tient dans un tableau `S` en haut du `<script>`. Une direction est un objet :

```js
{
  id:'ma-direction',            // identifiant unique, sans espace
  nom:'Nom affiché',
  tl:"Le style en une phrase.",  // apparaît sur la carte
  tags:['sombre','texture'],     // alimente les filtres automatiquement
  refs:"D'où ça vient : écoles, affichistes, objets, époques.",
  pal:{bg:'#…',surf:'#…',txt:'#…',mut:'#…',acc:'#…',acc2:'#…'},
  typo:{d:"famille CSS titre", b:"famille CSS texte",
        dn:'Nom lisible titre', bn:'Nom lisible texte'},
  ui:{ r:'8px',              // rayon des angles
       bw:'1px', bc:'#…',    // épaisseur et couleur des bordures
       sh:'0 2px 8px …',     // ombre, ou 'none'
       up:'uppercase',       // ou 'none'
       tr:'-.02em',          // interlettrage des titres
       dw:700, hs:'26px',    // graisse et taille du titre d'aperçu
       onacc:'#fff',         // texte posé sur l'accent
       tex:'…', texop:.4 },  // optionnel : motif de texture et opacité
  layout:"Les règles de composition.",
  avoid:"Ce qui trahit la direction."
}
```

Deux points à ne pas oublier :

- ajouter l'identifiant dans `PAIRS` pour les affinités ;
- si la typo demande une police web, l'ajouter au `<link>` Google Fonts en tête de fichier.

Les tags de filtrage se construisent tout seuls à partir des objets.

## Détails techniques

- Fichier unique, aucune dépendance JavaScript.
- Rien n'est stocké : la sélection et les réglages vivent le temps de la session.
- `Échap` ferme le panneau ou la modale ; le focus clavier reste visible partout ; `prefers-reduced-motion` est respecté.
- La copie utilise l'API presse-papier avec un repli sur `execCommand` pour les contextes restreints.

## Parti pris

Les palettes et les couples typographiques sont des points de départ, pas des dogmes. Décaler une teinte, changer une graisse, remplacer l'accent : la direction reste lisible. Ce qu'il faut garder intact, c'est la colonne **À éviter** — c'est elle qui tient le style debout.
